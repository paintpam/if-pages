# if-pages — ⚠️ www.paintpam.com 운영 페이지 원본 (공개 저장소)

이 저장소는 **코드 프로젝트가 아니라 라이브 사이트의 재료**입니다. 함부로 이름을 바꾸거나 지우면 사이트가 깨집니다.

## 무엇이 들어 있나

| 경로 | 내용 |
|---|---|
| `*.txt` | 아임웹 페이지 블록에 붙여 넣는 HTML/CSS 원본 (파일 하나 = 페이지 하나, 예 `memory-game.txt`) |
| `blocks/` | 여러 페이지가 공유하는 블록 조각 (`fm_body.txt` 등) |
| `assets/` | 페이지가 쓰는 이미지·영상. **사이트가 이 저장소 주소로 직접 불러오는 파일이 있다** (2026-10-28 기준 페이지 6개가 `assets/` 를 외부 URL 로 참조) |
| `green-pages/` `if-content-widgets/` `widgets/` `subs/` | 하위 페이지·위젯 묶음 |

## 규칙

- **`assets/` 안의 파일은 이름을 바꾸거나 지우지 않는다.** 교체할 땐 같은 이름으로 덮어쓴다. (공개 저장소라 사이트가 바로 링크한다)
- 저장소를 바꿔도 사이트에 자동 반영되지 않는다 — 배포 자동화가 없다. `.txt` 를 고친 뒤 아임웹 관리자에서 해당 블록에 다시 붙여 넣어야 한다.
- 이 저장소는 **공개**여야 한다(이미지 링크 때문). 회사 비공개 정보·개인정보·시크릿은 절대 넣지 않는다. brain 워치독이 org 공개 저장소를 매일 감시하며, 이 저장소만 허용 목록(`ORG_PUBLIC_REPO_ALLOWLIST`)에 있다.
- 콘텐츠(게임·키오스크) 자체는 여기 두지 않는다. 콘텐츠 저장소 규칙은 `paintpam/content-kit`.
